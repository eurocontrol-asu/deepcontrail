# deepcontrail-mtg

Converts MTG/FCI contrail labels from Encord exports (one JSON file per sequence) and the
matching per-frame `.npy` images into the [DeepContrail dataset format v1](https://github.com/eurocontrol-asu/deepcontrail/tree/main/packages/core). It is one producer of that format, not part of the library.

Not published yet.
